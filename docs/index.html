Pipeline Architecture

Layer 0  MESH          Traditional triangles → 3-MRT GBuffer (Color + Normal/Depth + ObjectID)
Layer 1  SPLAT         Gaussian point-sprite splats, depth-tested against mesh
Layer 2  PROCEDURAL    VIB3 fullscreen fragment shader (24 geometry variants × 3 warps)
Layer 3  INSCRIPTION   N-layer holographic edge overlay driven by GBuffer normals/depth/ID
         ——— COMPOSITOR ———
         Per-layer opacity · blend modes (alpha/additive/screen/multiply) · tone mapping · gamma
Scene Objects → SceneRenderer → Shared GBuffer (3 MRT)
                                           ↓
          Color (RGBA8)   Normal/Depth (RGBA16F)   ObjectID (RGBA8)
                ↓                           ↓
         Compositor L0             EdgeInscriptionLayer
                                              ↓
                                   InscriptionChannel
                                   (semantic state + audio)
                                              ↓
                                   Compositor L3

PBR Textures → PBRSplatConverter → Splats → Compositor L1
VIB3 Systems → Procedural Callback → Compositor L2

Key Capabilities

3-MRT GBuffer
Color + Normal/Depth + Object ID rendered in a single pass to three textures. Enables downstream edge detection and per-object inscription routing.
N-Layer Batched Inscription
1–16 procedural inscription layers composited in a single draw call via uniform arrays. Each layer has independent pattern, scale, color, speed, and blend mode.
Multi-Object Scenes
Multiple meshes rendered into a shared GBuffer with automatic ObjectID assignment and per-object inscription routing via identity hash.
Semantic State System
6 object states (idle, active, selected, powered, damaged, destroyed) with smooth parameter transitions. State drives inscription color, intensity, and pattern.
PBR → Splat Decomposition
Roughness, metallic, AO, and emissive PBR texture maps converted to oriented Gaussian splat distributions for hybrid rendering.
Audio-Reactive 4D Modulation
Bass→XW rotation, Mid→YW, High→ZW, Energy→all planes + glow intensity. Sound drives 4D hyperrotation and inscription parameters.
Morph Target Animation
GPU-side vertex blending between base and deformed meshes. Single float weight control for smooth morphing with full GBuffer participation.
Per-Object Identity
Deterministic hash of ObjectID produces unique inscription pattern per object. No artist configuration needed — every object is visually distinct.
WebGPU Compute Path
WGSL shared-memory edge detection + single-dispatch inscription for modern GPUs. Falls back to WebGL2 fragment shader path automatically.

API Quick Start

Pipeline Setup

import { MeshRenderer, GaussianSplatRenderer, EdgeInscriptionLayer,
         HybridRenderPipeline, InscriptionChannel } from './src/render/index.js';

const pipeline = new HybridRenderPipeline(gl, { exposure: 1.2, gamma: 2.2 });

// Layer 0: Mesh
pipeline.setMeshRenderer(new MeshRenderer(gl));

// Layer 1: Splats
pipeline.setSplatRenderer(new GaussianSplatRenderer(gl));

// Layer 3: Inscription (4 layers, single draw call)
pipeline.setEdgeInscription(new EdgeInscriptionLayer(gl, { layerCount: 4 }));

// Per-layer blend control
pipeline.meshLayer.opacity = 1.0;
pipeline.inscriptionLayer.blendMode = BlendModes.ADDITIVE;

Semantic States

const channel = new InscriptionChannel({ layerCount: 4 });
channel.registerObject(1, 'active');
channel.setObjectState(1, 'powered');   // smooth transition
channel.setAudio(bass, mid, high, energy);
channel.update(deltaTime);

Multi-Object Scene

const scene = new SceneRenderer(gl);
scene.addObject('hero', heroGeometry);
scene.addObject('terrain', terrainGeometry);
pipeline.setSceneRenderer(scene); // shared GBuffer, per-object inscription
